# Cereal Space

A 3D companion to [Ranking American Breakfast Cereals](https://taliahonikman.substack.com/p/ranking-american-breakfast-cereals). Open `index.html` in a browser. Three.js r128 and fonts load from CDNs; the score table works without WebGL or Three.js.

Drag to rotate, tap or point at a cereal to see its scores, use the tier buttons to filter, and search by name. The table is also available without using the chart. The axes measure structural integrity, milk palatability, and dry merit; sphere size represents cartoon effect. Point positions are jittered to separate overlapping scores. The essay explains the ratings and methodology.
